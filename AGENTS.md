# AGENTS.md 

The role of this file is to describe common mistakes and confusion points agents can encounter as they work in this project. If you encounter something in this project that makes you stuck or confused or surprises you, alert a developer working with you to indicate that this is the case in AgentsMD file to help prevent future agents from having the same issue.

This project is launched is dev environment and has no real users at all. So, don't worry to make mistakes.

# Developing approach

Tests: This project uses TDD, so developer may ask you to plan a test for a command that doesn't exist. Just try to suggest how it should work.

Commands: Try to write clean code. Extract checks to middlewares, duplicate logic or logic with different level of abstraction to private functions.
